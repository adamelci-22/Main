# Old-system tools (retired 2026-10-15)

Tools of the retired ORB breakout system (RULEBOOK v3.x, `archive/RULEBOOK_v3.132_full.md`). None is used by RULEBOOK v5.0. Kept for history; paths inside them assume their original locations (`tools/live/`, `tools/`, `tools/replay/`).

- `gate.py` — the C1 gate snapshot (RVOL, 30-minute ORB, selection_score).
- `profile.py` — the B1 risk profile (stall / minimum move) for the B2 ratchet.
- `replay/` — minute-resolution replays and the exit lab, with their data.
